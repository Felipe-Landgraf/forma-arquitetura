# Imagens e conteúdo

O Forma é um escritório fictício e os nomes dos projetos são conceitos criados para uma demonstração de desenvolvimento web. As fotografias são referências ilustrativas; não representam obras projetadas pelo Forma.

As seis fotografias foram obtidas no Unsplash e são distribuídas neste projeto como parte do layout, conforme a [licença do Unsplash](https://unsplash.com/license). A licença das fotografias não é substituída por uma licença geral do código.
